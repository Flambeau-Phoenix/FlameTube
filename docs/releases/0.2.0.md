# FlameTube 0.2.0

## Changes

- Live TV uses compact, single-column channel rows with favorites and source details.
- The top bar opens YouTube, Music, Live TV, and Twitch; Now Playing returns to the player.
- Optional Twitch device-code connection adds followed live channels and broadcaster profiles.
- Twitch chat includes theme, size, docking, browser popout, and Chatterino launch controls.
- HLS loads use normal playlist HTTP behavior rather than the file-download retry settings;
  ordinary YouTube playback restores its bounded reconnect settings.
- Pending Twitch login and refresh results cannot commit a session after cancellation or sign-out.
- Twitch API tokens are validated at startup and hourly, and refresh requests are serialized.
- Broadcaster cards ignore obsolete responses when changing channels.
- Twitch playback stops if the native player's pause command fails, rather than playing both.

## Build and verification

The Windows x64 installer is unsigned and bundles the pinned libmpv runtime described
in `scripts/setup-windows.ps1`. It uses the independent `app.flametube.desktop`
profile. It does not import an existing Limusic profile or bundle runtime data.

Validation includes zero Svelte diagnostics, 29 frontend self-checks, production UI
compilation, five IPTV tests, five Twitch backend tests, the native HLS/normal-load
transport regression, and the existing URL-opener regression. On Windows, the Rust
backend unit-test executable needs a Common Controls v6 manifest; Tauri's packaged
application already receives its application manifest during the normal build.

The extracted NSIS payload was launched successfully and reported version 0.2.0.
The Live TV list rendered full-width rows in one column. Twitch API status started
signed out, with no Client ID or account configured. A public CBS stream decoded at 1280 x 720 using an alternate source.
The bundled mpv DLL matched the
pinned build input byte for byte. The installer was extracted and smoke-tested;
it was not installed into the operating system as part of verification.

Installer: `FlameTube-Setup-0.2.0-x64.exe` (63,929,984 bytes).
SHA-256: `77c2e324bd7d4acd4985b2e4c76395281d56ed62f8a3fb34458c9fb4e8f81cd1`.

No real Twitch account is connected by automated tests. Device authorization and
embedded-chat login require the user's own account. They are separate sessions.

The source audit excludes profiles, databases, cookies, tokens, private keys, local
paths, recordings, and build outputs. The production dependency audit reported zero
known vulnerabilities at build time. This is not a claim that every development
dependency or future upstream release is free of vulnerabilities.
